A promotional site for my musical alter ego.

## About
Users are given the opportunity to view the entire discography, and link to a streaming service for listening. For myself made authorisation and the ability to manage the display of content.

## Features
- Ability to view the latest release and a list of all songs
- Ability for the administrator to add, modify and delete tracks

## Stack
### Client
- React
- React Helmet
- React Hook Form
- React Router
- Firebase
- Styled Components
- NanoID
- day.js
### Development
- TypeScript
- Vite.js
